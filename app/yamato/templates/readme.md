# app / yamato / templates

Go `html/template` files for the yamato wiki.

| Template | Page |
| --- | --- |
| `landing.html` | public landing page (before the IAP gate) |
| `wiki_index.html` | the wiki's article index |
| `article.html` | one article |
| `search.html` | search results |
| `noc.html`, `noc_dashboard.html` | the security NOC view used in the red-team demo |
| `partials.html` | shared header/footer partials |
